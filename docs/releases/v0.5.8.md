DeskGhost 0.5.8 for Windows x64.

## Download and run

Download **DeskGhost-v0.5.8-win-x64.zip**, extract the entire folder, and run **DeskGhost.exe**. Keep all files together. Electron and the .NET runtime are included; Node.js and the .NET SDK are not required on the target computer.

- **Ctrl+Alt+N**: create a task.
- **Ctrl+Alt+G**: open the task graph.
- See the included README for gestures, workspace storage, backup, and settings.

## Changes in 0.5.8

- Cancelling a new card with Esc disperses its particles, including during assembly.
- A delayed startup reply no longer reopens the board after it has been hidden with Esc.
- Existing connection endpoints remain draggable when a zoomed-out card's enlarged port hit area overlaps them.
- Includes the preceding task graph layout, first hotkey activation, gesture tolerance, focus, and saving improvements.

## Release validation

The Windows build runs the existing data integrity and Node checks, then the Electron interaction and saving checks against both the source application and the packaged executable. The portable package includes its runtime notices and font licences. SHA256SUMS.txt provides the archive checksum.

This is an unsigned portable application. An installer and automatic updates are not included. Native focus checks may report skipped subchecks when the CI desktop cannot grant foreground input; display scaling, Chinese input methods, and interactions with other applications still need verification on the target computer.
