# DeskGhost v0.5.9

Windows x64 portable release with improved card readability, workspace controls, and zoomed graph connections.

## Changes

- The task graph reserves two empty rows below its content or visible area. Scroll or middle-drag down before placing a card; scrolling alone does not create task records or expand the board without limit.
- Card descriptions use more of the available paper area while retaining a bottom margin.
- The workspace keycap grows with its name, so ordinary names are fully visible; very long names still fit within the available toolbar space.
- The new-workspace dialog has its paper background again.
- When zoomed out, dragging an existing connection endpoint works even if a port's transparent hit area overlaps it. Dragging the visible port itself still creates a new connection.
- Graph regression checks adapt to smaller viewports and verify card-return shadows at the displayed scale. The Windows workflow checks both source and packaged builds, then retains a ZIP and verified SHA-256 manifest.

This release also retains the card-assembly and cancellation particles, first-hotkey activation, Escape handling, gesture difficulty controls, and local saving improvements from the preceding version.

## Download and run

Download **DeskGhost-v0.5.9-win-x64.zip**, extract the entire folder, and run **DeskGhost.exe**. Keep all files together. Electron and the .NET runtime are included; Node.js and the .NET SDK are not required on the target computer.

- **Ctrl+Alt+N**: create a task.
- **Ctrl+Alt+G**: open the task graph.
- See the included README for gestures, settings, workspace storage, and recovery.

**SHA256SUMS.txt** records the archive's SHA-256 checksum. In PowerShell, run `Get-FileHash .\DeskGhost-v0.5.9-win-x64.zip -Algorithm SHA256` and compare the result with the manifest.

## Upgrading

Finish editing and exit the previous version before starting this one. Back up your workspace files, then extract the new version into a separate folder. Default settings and workspaces remain under `%LOCALAPPDATA%\DeskGhost`; users who launch with a custom `--data-dir` should keep using that directory. Workspace format remains version 2.

## Distribution and validation scope

This is an unsigned portable application without an installer or automatic updates. Runtime notices and the licences for bundled fonts are included. User workspaces, source artwork, development dependencies, and test data are excluded from the package.

The existing automated checks cover data integrity, gestures, direct graph manipulation, saving, cancellation, and Windows input focus. Display scaling across multiple monitors, Chinese input methods, and interactions with other applications still require verification on the target computer; performance limits have not been formally certified.
