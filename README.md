# DeskGhost 0.2.0

面向 Windows 的透明桌宠与任务图工具。当前版本使用 **Electron + HTML / CSS / Canvas**：没有传统 Windows 标题栏或边框，白色圆角三角碎片直接浮在桌面上，工作区、工具栏和任务卡片以半透明界面展开。字体暂用系统字体占位，后续再确定字体方案。

**v0.2.0 是已确认的 Electron / HTML 功能与视觉基线（baseline）**，后续开发以此版本为起点。旧 WPF 界面已移除，不再维护 Windows 原生界面的效果路线。保留的 .NET 10 `DeskGhost.Core` 与 `DeskGhost.Bridge` 仅承担数据逻辑及进程通信，继续提供兼容的工作区格式、安全保存和撤销历史。

## 运行与打包

开发需要 Windows、Node.js **22.12 或更新版本**及 **.NET 10 SDK**。在仓库目录运行：

```powershell
npm ci
npm start
```

`npm start` 会先构建数据服务。构建脚本优先使用仓库内的 `.tools/dotnet/dotnet.exe`，没有该文件时使用 PATH 中的 `dotnet`。

体验或验收时可使用独立数据目录：

```powershell
npm start -- --data-dir .local/demo
```

生成 Windows x64 便携目录：

```powershell
npm run build
```

输出为 `artifacts/desktop/DeskGhost-win32-x64/`，运行其中的 `DeskGhost.exe`。迁移应用时复制整个目录；其中已包含 Electron 和数据服务所需的 .NET 运行时，目标设备无需安装 Node.js 或 .NET SDK。当前没有安装器、自动更新或自动开机启动。

## 桌宠与直接操作

碎片使用 Boids 的分离、对齐与聚合行为，再结合形态目标、惯性、阻尼和个体差异形成圆环、任务卡片边缘及驻留形态。碎片为大小接近、边长有差异的白色圆角三角形。

| 操作 | 方式 |
| --- | --- |
| 直接创建任务 | `Ctrl+Alt+N`，跳过圆环准备状态 |
| 打开任务图 | `Ctrl+Alt+G`，或点击桌宠 / 托盘入口 |
| 鼠标召集 | 收起界面后连续同方向画两圈，直径约为当前屏幕高度的 1/4；允许顺逆时针、适度椭圆和尺寸偏差 |
| 从圆环开始输入 | 直接输入标题，无需等动画完成 |
| 下一栏 / 创建任务 | `Ctrl+Enter`，依次为标题、分类、内容，最后一栏提交 |
| 切换创建所属工作区 | `Alt+W` 后用键盘选择；分类可输入、检索或新建 |
| 取消准备 / 创建 | `Esc`；准备状态也可快速左右甩动鼠标驱散碎片 |
| 连接任务 | 从卡片右侧端口拖向后续卡片左侧端口，也可从左端口反向选择来源 |
| 改接连线 | 拖动已有连线的端点，放到另一张有效卡片上 |
| 断开连线 | 将已有连线端点拖到图中的空白处松开 |
| 移动卡片 | 直接拖动；预览目标位置，松手后平滑吸附到逻辑列与空闲行 |
| 查看 / 编辑任务 | 双击卡片，或选中后按 `Enter` / `F2` |
| 多选 / 汇合 | `Ctrl` 多选来源，再创建后续任务 |
| 移动画布 / 缩放 | 拖动空白处平移，`Ctrl` + 滚轮缩放；工具栏可适配整个任务图 |
| 查找 / 撤销 / 重做 | `Ctrl+F`、`Ctrl+Z`、`Ctrl+Y` 或 `Ctrl+Shift+Z` |

创建成功后进入任务图并定位新卡片。连线、断开、改接、移动和删除均可撤销；放置到无效位置时保留原有关系。动画和过渡不承担保存或输入时序，关闭效果后仍可创建、编辑和使用快捷键。

应用收起后保留桌宠与托盘。全局快捷键、手势开关、效果等级和新工作区存储目录均可配置；正常退出使用界面或托盘中的退出操作。

## 工作区与任务规则

- 同时最多打开 12 个工作区，每个独立保存任务、分类、逻辑时间列、布局、连线及归档历史。
- 逻辑时间列表示工作阶段，不对应实际日期。后续任务必须在全部来源右侧，默认放在最靠右来源的下一列；允许独立任务、分支、汇合和插入时间列。
- 状态为未开始、进行中、已完成、已停止，由用户手动修改。停止任务不影响后续任务，来源状态也不限制后续任务开始。
- 可切换任务图与分类视图，按标题、分类、状态筛选。匹配结果以标题列表呈现，点击定位对应卡片。
- 已完成或已停止任务可归档；归档保留内容、连线及归档 / 恢复历史。
- 删除进入回收站，只移除该卡片及其连线，不级联删除或自动重连。撤销删除恢复原卡片与连线；从回收站恢复只恢复卡片。
- 撤销 / 重做只保留在当前会话中，每个工作区最多 50 步、共 32 MiB。归档历史和回收站内容随文件保存。

## 数据、安全与恢复

默认工作区目录为 `%LOCALAPPDATA%\DeskGhost\Workspaces`，当前设置文件为同级的 `web-settings.json`。首次运行可读取旧版 `settings.json` 中的数据目录、打开文件和快捷键等设置，旧文件保持不变。`--data-dir` 改变配置目录与初始工作区目录；设置中更换数据文件夹只影响新建工作区，已打开的文件继续在原位置保存。

每个工作区是一个 UTF-8 `*.deskghost.json` 文件，含 `formatVersion: 1`，可直接复制用于导出、备份和迁移。复制前确认界面显示已保存。主要字段为 `id`、`name`、`categories`、`columns`、`tasks` 和 `links`；状态字符串为 `NotStarted`、`InProgress`、`Completed`、`Stopped`。列与行从 0 开始。文件不引用脚本或外部资源。

任务编辑自动提交，数据服务串行处理变更并等待保存结果。保存先写入同目录临时文件、刷新到磁盘，再原子替换主文件，并将上一份有效版本保留为 `.bak`。同目录 `.lock` 仅用于协调写入；迁移只需主文件，也可额外复制 `.bak`。文件系统不支持原子替换、权限不足或磁盘写入失败时，操作报告失败，不覆盖原有有效文件。

外部程序修改、移动或删除已打开文件时，应用拒绝覆盖。保存失败会保留内存中的更改，可重试保存或“另存并继续”到新文件。导出与另存拒绝覆盖已有目标文件及备份。尚有未保存数据时不会静默关闭工作区或正常退出。

损坏文件、未知版本、超限数据和无效图结构会被拒绝。使用“从备份恢复”选择主文件后，可从其 `.bak` 恢复；被替换的原文件会保留为独立 `.corrupt` 文件。异常退出后的恢复以最后一次成功保存或有效备份为准，尚未提交的输入可能丢失。

数据服务异常停止后，任务编辑停止。界面可将主进程保留的最后一份有效工作区快照导出到新文件；全部未保存工作区完成救援导出后才允许正常退出。该快照不包括尚未被数据服务确认的输入。

应用使用普通用户权限，无账户或云端同步，不修改无关系统配置。渲染器启用 sandbox、context isolation，禁用 Node 集成；仅通过白名单接口访问数据服务，阻止外部导航、远程资源与页面权限请求。后台手势通过采样鼠标位置实现，不安装全局键盘钩子。

| 处理对象 | 上限 |
| --- | --- |
| 单个工作区文件 / 同时打开的数据预算 | 16 MiB / 16 MiB；会话为历史最大快照预留空间 |
| 每工作区任务（包括归档、回收站） / 连线 | 2,000 / 8,000 |
| 逻辑时间列 / 分类 | 256 / 256 |
| 标题 / 内容 / 分类名称 | 256 / 16,000 / 80 个 UTF-16 字符单位 |
| 单任务归档历史 / 单次创建来源 | 200 / 256 |
| 鼠标轨迹 | 25 Hz 采样、最多 224 点、保留 6 秒 |

## 透明与效果边界

窗口覆盖当前显示器工作区，浮动界面之外的区域允许鼠标穿透；拖动图内对象期间暂时捕获输入。召集时会选择鼠标所在显示器。它仍是桌面上的透明窗口，系统安全桌面、独占全屏程序以及跨屏 DPI 行为需要在目标环境验证。

当前面板由 HTML 半透明材质与 CSS 模糊组成，不承诺对其他应用或桌面内容进行系统级实时毛玻璃模糊。浅色桌面上的白色碎片对比度仍需要人工评估。

视觉优先：默认高效果为 72 个碎片、最高 60 FPS，低效果为 42 个、最高 30 FPS；动画画布像素和计算步数均设上限。效果关闭、动画隐藏或页面不可见时停止相应渲染；驻留可见的桌宠仍会运动。关闭手势后不再识别轨迹。上述数值是实现配置，不是资源占用承诺；尚未确定 CPU、内存和功耗指标。

无法读取当前桌面的鼠标位置时，手势采样降为 1 秒、随后 5 秒间隔重试，并释放鼠标拦截；恢复访问后回到正常采样。系统休眠期间停止采样。

## 验证与待验收

```powershell
dotnet build src/DeskGhost.Bridge/DeskGhost.Bridge.csproj --configuration Release
dotnet run --project tests/DeskGhost.Checks/DeskGhost.Checks.csproj --configuration Release
npm test
npm run test:ui
```

`npm test` 运行集中维护的 Node 检查。`npm run test:ui` 在 Windows 上启动真实 Electron，验证透明像素与隔离选项、拖拽连接 / 断开、吸附、撤销、全键盘创建、查找和文件保存；使用 `.local/web-smoke` 下的独立数据目录并保存截图。Core 检查覆盖图规则、原子改接、状态、归档、删除、历史、格式校验、冲突检测及安全保存。CI 构建数据服务并运行这些检查，当前唯一的界面运行与发布目标为 Electron / HTML 桌宠。

仍需人工验收：

- 中文输入法首字、组合输入和分类检索；动画开始时立即输入。
- 真实鼠标双圈 / 甩动的误触率、桌面点击穿透，以及不同显示器、缩放比例、负坐标和跨屏使用。
- 全局快捷键冲突、托盘操作、与其他应用切换焦点及独占全屏场景。
- 磁盘空间不足、断电、移动磁盘断开、损坏主文件 / 备份、数据服务异常停止后的救援流程。
- 0 / 500 / 2,000 任务下的输入延迟、动画帧率、CPU、内存和功耗；据此调整最终默认效果。

当前代码入口为 `desktop/main.cjs`、`desktop/web` 和 `src/DeskGhost.Bridge`；公共数据逻辑位于 `src/DeskGhost.Core`。测试集中在 `tests/DeskGhost.Checks` 与 `tests/desktop.test.cjs`。
